# Labmill client

Labmill client is for researchers who already run their code on their own Mac or Windows computer, often on a single GPU, and now need more. You say what you want to run in a chat, and Labmill finds your data, moves it to a Slurm cluster, runs the job, and brings the results back.

Labmill client works with Slurm clusters. It uses your own cluster account and your own Anthropic API key.

Labmill is under active development. See the [user guide](user/index.md) for what works today, and the [developer pages](dev/index.md) if you want to build it or change it.
