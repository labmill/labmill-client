# Labmill icon

A lowercase **y** whose right arm rises into a throwing arc that ends in an arrowhead: "describe it, yeet it, compute it". It sits on a rounded tile with a blue→violet gradient (`#1E40AF` → `#7C3AED`).

| File | Use |
|---|---|
| `labmill.svg` | vector master (docs site, README banner) |
| `labmill-<n>.png` (16–1024) | window icon, app bundles, docs |
| `labmill.ico` | Windows exe and window icon (16–256) |
| `labmill.icns` | macOS app bundle |
| `tray-light-*.png`, `tray-light.ico` | tray icon on dark taskbars and menu bars |
| `tray-dark-*.png`, `tray-dark.ico` | tray icon on light taskbars and menu bars |

The raster files are generated with Pillow by `tmp/icon/make_icon.py`, which is kept out of the repo (gitignored `tmp/`). The SVG uses the same geometry.
