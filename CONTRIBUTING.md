# Contributing

Thank you for helping with the Labmill client.

- **Pull requests are welcome.** GitHub runs no tests for pull requests. A maintainer reads your pull request, copies it to a branch on the Labmill build server and runs the full tests there, offline. Then it is merged by hand, so your pull request can show as closed, not merged. Your commits keep your name.
- **Before you send it:** run `make check` (format, vet, tests). Keep changes small, one topic per pull request.
- **Security issues:** do not open a public issue. Write to help@labmill.org.
- **Releases** are built on GitHub Actions from version tags (`v*`) and published by a maintainer.
